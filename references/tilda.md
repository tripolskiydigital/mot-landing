# Перенос лендинга в Tilda и подача в Made on Tilda

Сверено со справкой Tilda 19.11.2026 (https://help-ru.tilda.cc/zero, /zero/animation, /zero/advanced-animation,
/zero/trigger-animation, /html, /fonts, /fontsgoogle). Пометка **[проверить]** — в справке не нашёл, проверь там же или в редакторе.

## 1. Стратегия: что куда
- **Каждая секция = Zero Block.** В выборке Zero Block есть у 96 % сайтов, медиана — половина всех блоков страницы.
  Тексты, фото, фигуры, линии, кнопки, рамки с уголками и служебные моно-подписи — штатные элементы Zero.
- **Генеративная графика и сложный JS** (canvas, SVG из скрипта, тест, ползунок, превью за курсором) — HTML-элемент внутри Zero Block
  или отдельный блок **T123 «HTML-код»** (Библиотека блоков → «Другое»).
- **Общие CSS и JS** (токены цвета, зерно, курсор, наблюдатели) — один раз на весь сайт: «Настройки сайта» → «Ещё» →
  «HTML-код для вставки внутрь head». Для одной страницы: «Настройки страницы» → «Вставка кода» → «HTML-код для вставки внутрь head».
- Сайт целиком кодом (один блок T123) тоже бывает (ot-01, bu-08), но для подборки и правок клиентом лучше Zero + точечный код.

## 2. Zero Block: сетка, брейкпоинты, позиционирование
- **Брейкпоинты по текущей справке:** ≥ 1200 (десктоп), 980–1200 (планшет горизонтально), 640–980 (планшет вертикально),
  480–640 (смартфон горизонтально), 360–480 (смартфон вертикально). В старых проектах встречаются 960 и 320 — смотри,
  что стоит в редакторе. Свои брейкпоинты — иконка настроек рядом с переключателем экранов, от 360 до 2560 px.
- **Каждый брейкпоинт собирается отдельно**: значения наследуются сверху вниз (унаследованные — серым, изменённые — чёрным).
  Мобильная версия — это не «сжатие», а своя раскладка; закладывай время на 5 экранов. Высота артборда задаётся на каждом.
- **Контейнеры:** Grid Container — 1200 px, 12 колонок, объект держится в сетке; Window Container — вся ширина окна.
  Вордмарк «в край окна», фон-фактура, линии на всю ширину — привязывай к Window. Начало координат (синий крестик) меняется
  на любой угол: прижатое к низу название — привязка к нижнему краю.
- **Координаты** X/Y — px или %; ширина и высота по справке в px [проверить: единицы % для ширины в текущей версии].
- Z-index числом, Position: Fixed или Absolute (фикс — для капсулы меню, кнопки «Купить билет», статуса), Overflow: Visible / Hidden / Auto,
  группы до 5 уровней вложенности. Тултипы проверять на всех экранах — их режет край блока.
- **Гигантское слово:** кегль задаётся на каждом брейкпоинте вручную (скрипт подгонки из `code-illustration.md` тут не нужен, если
  слово — штатный текст). Трекинг гигантов — отрицательный, интерлиньяж 0,8–0,95 в поле line-height элемента.

## 3. Анимация Zero Block
**Базовая (появление):** Fade In, Fade In Up / Down / Left / Right, Zoom In. Параметры: Duration, Delay (с), Distance (px, для
направленных), Trigger Offset (px от нижнего края окна), Scale (для Zoom In).
**Эффекты при скролле:** параллакс по скроллу (Speed: < 100 % медленнее прокрутки, > 100 % быстрее — для «0,85 / 1,1» ставь 85 и 110),
параллакс по движению мыши (дистанция по X и Y), Fixing — фиксация (зона старта On Window Top / Center / Bottom, Trigger Offset, Distance).
**Пошаговая (Step by step, SBS)** — помечена BETA:
- События (Event): **Element on Screen**, **Block on Screen**, **On Scroll** (идёт вместе с прокруткой), **On Hover**, **On Click**.
- Старт: Start Trigger (On Window Top / Center / Bottom), Trigger Offset; **Loop** — зацикливание.
- Шаг: Duration, Move (смещение), Scale (%), Rotate (°), Opacity, Easing (Linear, easeIn, easeOut, easeInOut, bounceFin), Delay.
- Чтобы элемент стартовал невидимым — первый шаг Opacity 0, Duration 0. SBS отменяет базовую анимацию элемента.
  Проверка — Play Element / Play All и предпросмотр после сохранения.
**Триггерная:** анимация одного элемента запускается наведением или кликом по другому (Event On Hover / On Click → Add trigger → клик по элементу-триггеру).

Как перевести приёмы демо в SBS:
| Приём | В Tilda |
|---|---|
| Выезд букв по одной (40–60 мс) | каждая буква — отдельный текстовый элемент; Element on Screen: шаг 0 (Opacity 0, Move Y +40, 0 с) → шаг 1 (Opacity 1, Move 0, 0,8 с, easeOut), Delay +0,04 с на букву. Маска «из-под строки» штатно не делается — нужна обрезка группой или HTML [проверить overflow у группы] |
| Карточки «падают» с поворотом, билет −8° → −4° | Element on Screen: Rotate + Move Y, easeOut |
| Стрелка ↗ поворачивается на 45° | On Hover: Rotate 45, 0,3 с (триггер — вся кнопка) |
| Параллакс фото 0,85 / 1,1 | базовый параллакс Speed 85 % / 110 % |
| Манифест «проявляется» по прокрутке | On Scroll: Opacity 0,2 → 1 по словам или строкам |
| Шаги веером → в ряд | On Scroll: Rotate ±18 → 0 и Move X |
| Бесконечное вращение орбиты, «дыхание» сферы | SBS с Loop (Rotate 360 / Scale 106 %) |
| Счётчики, прорисовка stroke-dashoffset, маркер, смена слов, курсор | только код (head или HTML-элемент) |

## 4. Что Tilda делает штатно, а что — кодом
**Штатно:**
- Поп-апы: блоки поп-апа, кнопка-ссылка вида `#popup:имя` (так устроена и сама страница Made on Tilda). Формы — элемент «Форма»
  в Zero (поля в Input fields, приём данных в Services) или блоки форм; 2–4 поля, в поп-апе или в конце.
- Бегущая строка: в Библиотеке блоков есть готовые блоки бегущей строки [проверить номер и настройки скорости]; свою в Zero —
  две копии строки рядом, SBS Element on Screen + Loop, Move X на ширину копии, Linear. Замедление на hover штатно — нет.
- Меню-строка и капсула: блоки меню или Zero-фигура с радиусом и Position: Fixed; кнопки — элемент «Кнопка» (радиус, обводка, hover).
- Галерея/лента (Stretch, Loop, Arrows, Dots — Autoplay не включай в hero), тултипы, видео, иконки, Lazy Load у изображений.
- Квиз и «табы»: в Библиотеке есть блоки квиза и вкладок [проверить]; простые табы в Zero — триггерная анимация On Click
  (показать/скрыть слои Opacity).
**Только кодом (HTML-элемент в Zero или T123):**
- canvas: звёздное небо, растровый портрет; генеративные SVG: топокарта, аватары по хешу, керамика из профиля;
- кастомный курсор, превью за курсором, подгонка кегля под ширину, живые часы, счётчики, ползунок, тест с ветвлением, звук;
- SVG-фильтры feTurbulence. Статичное зерно и фактуру проще отдать картинкой: SVG-файл с фильтром как изображение
  или CSS-фон из head.

Правила для кода в Tilda (справка /html):
- В редакторе и предпросмотре код показывается текстом — работает **только после публикации**. PHP не выполняется.
- Не стилизуй теги, `*` и общие классы — заденешь интерфейс редактора и чужие блоки. Только свой префикс: `.mot-…`, `#mot-…`.
- Поддержка Tilda по своему коду не консультирует; внешние скрипты подключай `<script src>` в head или T123.
- Доступ к штатным элементам Zero из своего JS — по атрибуту `data-elem-id` элемента в опубликованном коде [проверить];
  Zero Block рендерится скриптом, поэтому свой JS запускай после `load` или наблюдай за DOM (MutationObserver) [проверить].
- HTML-элемент тоже позиционируется по брейкпоинтам; на телефоне тяжёлый canvas лучше заменить статичной картинкой
  (скрыть элемент на мобильных брейкпоинтах) [проверить, где переключатель видимости элемента].

## 5. Шрифты
- «Настройки сайта» → «Шрифты» → «Расширенные настройки» → вкладка **Google Fonts**. Либо поиск по библиотеке («Искать в шрифтах»,
  с включённой кириллицей), либо ссылка с fonts.google.com (фильтр Cyrillic) в поле **CSS link** — только адрес вида
  `https://fonts.googleapis.com/css2?family=Unbounded:wght@300;500&family=Inter+Tight:wght@400;500&display=swap`.
- Поля «Шрифт для заголовков» и «Шрифт для текста» — точное название семейства, как в Google Fonts. Для двух шрифтов — одна ссылка
  с обоими. Сохранить → «Publish all pages». Не применился — сбрось стиль кнопкой «очистить стиль».
- Третий шрифт (моно для служебного слоя): подключить той же ссылкой и задать через свой CSS-класс в head [проверить, доступен ли он
  в списке шрифтов Zero Block]. Свои шрифты — вкладка «Загрузить шрифт» (.woff / .woff2).

## 6. Ограничения и качество
- **Вес:** фото сжимай до загрузки (WebP/JPEG ≤ 300–400 КБ на кадр, hero-видео ≤ 3–5 МБ без звука); у изображений Zero включай Lazy Load,
  hero оставляй без него. Своя графика кодом весит килобайты — это аргумент за неё.
- **Мобильная:** собирается вручную на каждом брейкпоинте; гигантское слово переносится в 2–4 строки, сплит → колонка,
  кнопка видна без прокрутки, тяжёлые canvas/видео скрыты или заменены картинкой. Проверь 360 и 480 отдельно.
- **Cookie-плашка** — компактная, ≤ 15 % экрана телефона: у большинства сайтов выборки она закрывает 20–35 %.
- Пошаговых анимаций много — норма (медиана топ-25 — 59 элементов), но каждая должна быть только про `transform`/`opacity`.
- После публикации прогони `scripts/shoot.mjs` по живому адресу на 1440 и 390: `hScroll:false`, `invisible:0`, `errors:[]`.

## 7. Как подать сайт в подборку
1. Открой https://tilda.cc/ru/madeontilda/ → ссылка «Присылайте ссылки на сайты» → поп-ап «Спасибо, что решили поделиться
   проектом!» с одним обязательным полем **«Ссылка на сайт»** (на 19.11.2026). Выбора категории в форме нет — категорию и сам отбор
   делают дизайнеры Tilda («наши дизайнеры выберут лучшие и опубликуют»). Поэтому категория должна читаться с первого экрана:
   событие — с датой, магазин — с каталогом и ценами, курс — со стартом и программой.
2. Требование со страницы формы: сайт **завершён, адаптирован под мобильные, все ссылки и кнопки работают**.
3. Перед отправкой: опубликован на своём домене или `*.tilda.ws` (в топе выборки есть оба варианта), нет заглушек и «lorem»,
   формы подключены к приёму данных, есть favicon и OG-картинка, чек-лист из SKILL.md даёт ≥ 22 «да».
4. Сроки рассмотрения и ответ не обещаны [проверить]; Tilda публикует отобранные проекты и в своих соцсетях.
