# Плейбуки категорий Made on Tilda

Основа — разбор 160 главных страниц (по 20 на категорию, ноябрь 2026). «N из 20» — ручной подсчёт по скриншотам (±2).
Медианы в шапке каждой категории: высота страницы / число блоков / самый крупный кегль / доля тёмных сайтов.
Все шрифты ниже — Google Fonts, кириллица проверена запросом к css2 API (19.11.2026). Без кириллицы: Bebas Neue, Space Mono,
Instrument Serif, Fraunces, DM Serif Display — их не брать.

Как пользоваться: выбери категорию → возьми одну формулу первого экрана, одну шрифтовую формулу и одну палитру →
скелет секций → сверь с анти-паттернами → открой демо и 2–3 сайта из топа категории.
