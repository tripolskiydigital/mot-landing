# mot-landing — скилл для лендингов уровня Made on Tilda

Скилл для [Claude Code](https://claude.com/claude-code). С ним агент делает одностраничные лендинги, которые могут попасть в подборку [Made on Tilda](https://tilda.cc/ru/madeontilda/). У каждого такого лендинга одна визуальная идея, сильный первый экран, выверенная типографика и анимация. Свёрстан он кодом (HTML/CSS/JS) и готов к переносу в Tilda.

Правила скилла не придуманы, а выведены из разбора **160 главных страниц** подборки: по 20 свежих сайтов в каждой из восьми категорий (ноябрь 2026).

## Что умеет

- Собрать бриф за одно сообщение и сформулировать концепцию: метафору, сквозной приём, палитру и шрифты.
- Сверстать страницу по плейбуку нужной категории:
  - бизнес;
  - магазин;
  - событие;
  - медиа;
  - портфолио;
  - образование;
  - персональные;
  - другое.
- Нарисовать иллюстрации кодом (SVG, CSS, canvas), если своих фото нет.
- Проверить результат скриптом-скриншотером на 1440 и 390 px. Скрипт ловит горизонтальный скролл, невидимые блоки и ошибки консоли.
- Оценить страницу по чек-листу рейтинга из 30 пунктов. Уровень подборки — от 22 «да».
- Подсказать, как перенести вёрстку в Zero Block и подать сайт в подборку.

## Установка

Склонируйте репозиторий в папку скиллов Claude Code:

```bash
git clone https://github.com/tripolskiydigital/mot-landing.git ~/.claude/skills/mot-landing
```

Для проекта, а не для всех проектов, — в `.claude/skills/mot-landing` внутри проекта.

Для проверки скриншотами нужны Node.js 18+ и Playwright:

```bash
npm i -g playwright && npx playwright install chromium
```

Если Playwright установлен в другом месте, укажите путь к пакету в переменной `PW_PATH`.

## Как пользоваться

Скилл включается сам, когда вы просите сделать лендинг, одностраничник или промо-сайт. Например:

> Сделай лендинг для студии керамики в Казани — чтобы мог попасть в Made on Tilda.

> Проверь мою главную страницу по чек-листу Made on Tilda.

Можно вызвать его и явно: `/mot-landing`.

Скрипт проверки можно запускать отдельно:

```bash
node ~/.claude/skills/mot-landing/scripts/shoot.mjs http://127.0.0.1:8000/ shot.jpg 1440
```

Аргументы: адрес, файл, ширина (по умолчанию 1440), `0` — только первый экран. Скрипт печатает `{height, hScroll, invisible, errors}`; норма — `hScroll:false`, `invisible:0`, `errors:[]`.
